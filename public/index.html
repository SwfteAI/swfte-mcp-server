Swfte MCP server

Build, validate and deploy Swfte workflows, agents, chatflows and modules from any MCP client. This page is not the server — the endpoint is /mcp, and it speaks JSON-RPC over HTTP, not HTML.

Add it to Claude Code

claude mcp add --transport http swfte https://<this-host>/mcp
claude mcp login swfte

Add it to any other MCP client

Point it at https://<this-host>/mcp with the streamable HTTP transport. Every request carries its own credential; the server holds none.

Prefer to run it yourself?

npx -y @swfte/mcp-server

The stdio install reads a personal access token from SWFTE_PAT. The hosted endpoint above does not need one — you log in from the browser instead.
