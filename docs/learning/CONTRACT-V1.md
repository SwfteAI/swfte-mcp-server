# Learning W4/W5 MCP integration contract

Backend immutable authority: agents-service commit 5a2ef99fb, docs/learning/CONTRACT-V1.md. Default off: learning-capabilities.ts learningEnabled(client,config) requires local enabledGroups.has('learning') AND the authenticated backend /v2/learning/capabilities mcp=true. Missing/malformed/unavailable denies. No global cross-credential cache. All flags stay off in shipped defaults.

Stable worker boundaries: worker1 owns src/tracing.ts,src/client.ts,src/server.ts,src/tools/learning.ts and tracing/review tests; worker2 owns src/tools/recipes.ts,src/resources.ts,src/prompts.ts and book tests. Coordinator owns src/learning-contract.ts,src/learning-capabilities.ts,src/tools/index.ts,shared constants/config and this contract.

Book exports: resources.ts adds LEARNING_RESOURCE_TEMPLATES and async listLearningResources(client,config), and preserves existing STATIC_RESOURCES,RESOURCE_TEMPLATES,readResource. URI swfte://recipes/{id}, swfte://fragments/{id}, swfte://playbooks/{id}; read ref calls existing backend ID detail, validates kind, defaults read-only and quotes content. No client ranking. Missing/foreign/off same ResourceNotFoundError('Not found'). prompts.ts preserves four existing PROMPTS/getPrompt output bytes, adds LEARNING_PROMPTS and async getLearningPrompt(name,args,{client,config}). Named reuse-recipe takes query, fix-my-workflow takes executionId. Quoted fetched descriptions are data; embedded instructions never become the instruction rail. Tools recipes exports recipeTools registered into existing learning group by coordinator; swfte_recipes_search/get/apply,swfte_diagnose_failure use frozen backend endpoints and names. Apply only sandbox; never invent environment/proof.

Tracing: one tool trace, new span per HTTP attempt/subrequest, exactly final swfte-trace trailer, normalized host from initialize only, never raw host. Unreached queue bounded200, flush at most50 per authenticated payload, every item retains origin session/client/workspace partition; no recursive trace ingestion. Self outcomes/proposals create human-review rows only. All hosted auth resolved per request. Call/list/read/prompt gate at consumption, not only registration.

Codex docs were checked against official MCP and noninteractive documentation 2026-10-01: https://developers.openai.com/codex/mcp and https://developers.openai.com/codex/noninteractive. New adapter invocations use codex exec --json --sandbox workspace-write. No package publication or config secrets.
